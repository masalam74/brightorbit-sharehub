# BrightOrbit ShareHub

**One Link. Your Entire Workshop.**

BrightOrbit ShareHub is an interactive workshop management platform for independent trainers, tutors and educational organizations.

**Phase 1:** Market-validation prototype.

**Core features:** Workshop creation, registration, attendance, feedback, certificate previews, guided onboarding and referral sharing.

**Technology:** React, TypeScript and Cloudflare-compatible hosting.

**Deployment:** Cloudflare Workers.

**Payments:** Not included in the initial prototype.

**Owner:** BrightOrbit Labs.
